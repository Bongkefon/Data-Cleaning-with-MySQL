# Data-Cleaning-with-MySQL
By using a warehouse data set (https://github.com/eyowhite/Messy-dataset), this projects helped me to apply SQL skills such as data profiling, deduplication using window functions, standardization and table restucturing to clean the dataset.

# Notice
During the cleanig process, I noticed multiple instances where the same product_id was associated with different product name, category, warehouse, location, quantity, supplier, current_status and last_restocked. This indicates an inconsistent use of product identifiers, leading to conflicting values and duplicate records.
